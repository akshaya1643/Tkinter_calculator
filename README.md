# Tkinter_calculator
🧮 Calculator Application using Tkinter

A simple, user-friendly Calculator GUI application built using Python’s Tkinter library. This project demonstrates the fundamentals of desktop application development and GUI design, making it ideal for beginners.

📌 Features

✔ Basic arithmetic operations

➕ Addition

➖ Subtraction

✖ Multiplication

➗ Division

✔ Clean and modern dark-themed interface

✔ Responsive button clicks

✔ ❌ Clear (Reset) functionality

✔ ⚡ Lightweight and fast

✔ 🔒 Window maximization disabled for fixed layout

🛠️ Technologies Used

| Technology   | Purpose                 |
| ------------ | ----------------------- |
| **Python 3** | Programming language    |
| **Tkinter**  | GUI development library |

🚀 Getting Started

🔧 Prerequisites

Make sure Python 3 is installed on your system.

Check version:

bash

python --version


Tkinter comes pre-installed with Python, so no extra installation is required.

📂 Installation & Execution

1️⃣ Clone the repository

git clone https://github.com/akshaya1643/Calculator-using-Python.git

2️⃣ Move into the project folder

cd Calculator-using-Python

3️⃣ Run the application

python Calculator.py

⚙️ How It Works

The Entry widget displays user input and results.

Each button click triggers a function.

The mathematical expression is evaluated using Python’s eval() function.

The Clear (C) button resets the display.

entry.inset(0, value)
